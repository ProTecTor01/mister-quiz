# Mister Quiz

Mister Quiz — веб-викторина на Laravel 8. Игрок регистрируется, отвечает на вопросы из пяти категорий и получает XP за правильные ответы. В профиле видны личная статистика и звание; на странице лидеров — десять игроков с наибольшим XP.

## Быстрый запуск

Понадобятся PHP 8.2 или новее с расширениями `pdo_sqlite`, `mbstring`, `xml` и Composer. Для работы с MySQL вместо SQLite нужен `pdo_mysql`. Node.js и сборка фронтенда не нужны: CSS уже находится в `public/css/app.css`.

```bash
composer install
cp .env.example .env
php artisan key:generate
```

Создайте пустой файл `database/database.sqlite`. В Linux/macOS: `touch database/database.sqlite`. В PowerShell: `New-Item database/database.sqlite -ItemType File`. Затем выполните:

```bash
php artisan migrate --seed
php artisan serve
```

Откройте адрес, который выведет `php artisan serve` (обычно `http://127.0.0.1:8000`). В `.env.example` уже выбран SQLite; файл базы не попадает в Git. Для MySQL задайте в `.env` значения `DB_CONNECTION=mysql`, `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`, создайте базу и выполните те же миграции с заполнением.

## Как играть

На главной странице гость видит **Login**, **Leaderboard** и **Start Quiz**. Последняя кнопка переводит гостя на страницу входа. Вход выполняется по email и паролю; регистрация требует имя пользователя, email, пароль и подтверждение.

После входа доступны **Profile** и **Logout**. Викторина выбирает по четыре случайных вопроса из категорий Art, History, Geography, Science и Sports. Набор сохраняется в базе, поэтому обновление страницы и повторное нажатие **Start Quiz** продолжают ту же незавершённую игру. Каждый вопрос требует одного ответа. После отправки открывается страница с общим результатом и результатами по категориям. Повторная отправка завершённой игры не начисляет XP снова.

Правильный ответ начисляет XP, указанный у вопроса. В профиле для каждой категории хранятся правильные и все ответы в формате `x/y`; страница показывает также процент. Звания: до 1500 XP — Quiz Aprentice, от 1500 — Average Quizer, от 5000 — Epic Quizer, от 10000 — Quiz Master. Профиль виден только его владельцу. Leaderboard открыт всем и показывает десять лучших по XP.

## Данные и устройство проекта

`php artisan migrate --seed` загружает 60 вопросов и 240 вариантов ответа из `database/seeders/questions.json`. Это данные из архива задания, сохранённые в переносимом формате. Повторный запуск `php artisan db:seed` обновит существующие вопросы и не создаст дубликаты.

- `routes/web.php` — адреса страниц и ограничение доступа.
- `app/Http/Controllers/Auth/` — регистрация, вход и выход.
- `app/Http/Controllers/Questions/QuestionController.php` — выбор вопросов, проверка ответов и начисление XP.
- `app/Http/Controllers/ProfileController.php` и `LeaderboardController.php` — статистика игроков.
- `database/migrations/` — схема базы; `resources/views/` — шаблоны страниц.
- `mister-quiz__ts.md` — исходное задание и аудит-лист.

## Проверка

```bash
php vendor/bin/phpunit
```

Тесты используют SQLite в памяти. Они проверяют вход и регистрацию, доступ гостя, неизменность незавершённой викторины, обязательность и корректность ответов, начисление XP ровно один раз, результаты, защиту чужой игры, профиль и таблицу лидеров. Для ручной проверки пройдите пункты раздела `AUDIT` в `mister-quiz__ts.md` после запуска сервера.

Исходная заготовка использует Laravel 8. На момент подготовки проекта `composer audit` сообщает о трёх предупреждениях для этой ветки фреймворка. Перед размещением приложения на публичном сервере нужно обновить Laravel и повторить проверку зависимостей.
